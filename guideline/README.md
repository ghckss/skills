# Guideline

`guideline`은 처음 접하는 설정, 배포, 마이그레이션, 운영 작업을 사용자가 이해하면서 완료할 수 있도록 안내하는 Codex 스킬입니다. 전체 여정을 먼저 보여 준 뒤, 현재 단계에 필요한 내용만 구체적으로 설명하고 결과를 확인한 다음 다음 단계로 넘어갑니다.

## 언제 사용하나요?

다음과 같은 요청에 적합합니다.

- 처음 해보는 설치나 환경 설정을 순서대로 진행할 때
- 배포, 도메인 연결, 인증, 데이터 이전처럼 여러 시스템이 연결된 작업을 배울 때
- 각 선택지의 비용, 보안, 권한, 복구 가능성을 이해하면서 결정하고 싶을 때
- 화면이나 명령 결과를 확인해 가며 문제를 해결하고 싶을 때

단순한 사실 확인, 짧은 명령 하나, 설명 없이 결과만 만들면 되는 작업에는 일반적인 응답이 더 적합합니다.

## 핵심 동작

### 1. 전체 여정을 먼저 정리합니다

최종 목표와 현재 상태를 확인하고, 필요한 주요 단계와 의존 관계를 짧게 보여 줍니다. 이후 단계의 세부 지시를 한꺼번에 쏟아내지 않고 지금 수행할 단계만 자세히 안내합니다.

### 2. 한 번에 한 단계씩 진행합니다

각 단계에서 필요한 경우 다음 정보를 제공합니다.

- 이 단계의 목표와 필요한 이유
- 시작 전에 준비되어야 할 상태
- 실행할 명령이나 UI 경로
- 선택해야 할 값과 권장 이유
- 성공 여부를 판단할 수 있는 결과
- 비용, 보안, 데이터 손실과 관련된 주의점
- 다음 단계로 넘어가기 위한 확인 항목

Codex가 결과를 직접 검증할 수 있으면 사용자에게 같은 확인을 반복해서 요구하지 않습니다. 반대로 사용자가 직접 배우며 진행하기를 원하면 작업을 대신 수행하지 않고 안내 중심으로 협업합니다.

### 3. 오류가 발생해도 현재 위치를 유지합니다

오류 메시지, 스크린샷, 예상과 다른 메뉴가 나타나면 해당 정보를 현재 단계의 일부로 다룹니다. 문제의 의미, 가능한 원인, 가장 짧고 안전한 복구 방법을 설명한 뒤 원래 진행 단계로 돌아옵니다.

### 4. 위험한 작업 앞에서 멈춥니다

비용 발생, 권한 확대, 외부 공개, 데이터 삭제, 되돌리기 어려운 변경이 예정되어 있으면 영향과 복구 방법을 먼저 설명합니다. 환경에서 승인이 필요한 작업은 실행 직전에 명시적으로 확인합니다.

## 사용 예시

```text
$guideline으로 처음부터 AWS에 웹 서비스를 배포하는 과정을 안내해 줘.
```

```text
$guideline을 사용해서 기존 도메인을 새 호스팅 서비스로 옮기고 싶어. 초보자도 이해할 수 있게 한 단계씩 진행해 줘.
```

```text
$guideline으로 PostgreSQL 데이터를 새 서버로 마이그레이션해 줘. 각 단계의 검증 방법과 롤백 방법도 설명해 줘.
```

## 진행 중 기대할 수 있는 응답

처음에는 다음과 같이 전체 흐름을 간단히 제시합니다.

```text
목표: 기존 서비스를 새 환경으로 안전하게 이전

1. 현재 환경과 데이터 확인
2. 새 환경 준비
3. 시험 이전 및 검증
4. 실제 전환
5. 모니터링과 기존 환경 정리

현재는 1단계만 진행합니다.
```

각 단계가 끝나면 실제 출력이나 화면 상태를 기준으로 성공 여부를 확인합니다. 긴 중단이나 우회가 있었을 때는 완료한 단계, 현재 단계, 남은 결정 사항을 다시 정리합니다.

## 안전 원칙

- 비밀번호, 액세스 토큰, 개인 키, 결제 정보의 공유를 요구하지 않습니다.
- 비용이나 외부 노출이 시작되는 시점을 미리 알립니다.
- 삭제나 덮어쓰기 전에는 대상과 복구 방법을 확인합니다.
- 기억에 의존한 UI 명칭보다 사용자가 실제로 보고 있는 화면과 확인된 제품 동작을 우선합니다.
- 작업 완료 여부는 클릭 횟수가 아니라 관찰 가능한 결과로 검증합니다.

## 파일 구성

```text
guideline/
├── README.md
├── SKILL.md
└── agents/
    └── openai.yaml
```

- [`SKILL.md`](./SKILL.md): Codex가 따르는 전체 실행 지침
- [`agents/openai.yaml`](./agents/openai.yaml): 표시 이름, 설명, 기본 호출 프롬프트

동작을 변경할 때는 README의 설명뿐 아니라 `SKILL.md`의 계약과 `agents/openai.yaml`의 호출 문구가 서로 일치하는지 확인해야 합니다.
